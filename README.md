# 布伦特原油 · 每日开盘价台账

两个页面，一个仓库，全自动运行：

| 页面 | 内容 | 数据源 |
|---|---|---|
| `/` | 布伦特原油每日开盘价、最高、最低、跳空、成交量 | 新浪财经 `OIL` 日线 |
| `/spread` | 布伦特 × 柴油（EN590 基准）价差台账 | 东方财富 `112.B00Y` / `112.G00Y` |

数据由 GitHub Actions 每 30 分钟自动抓取、归档、提交，页面由 GitHub Pages 托管。
不需要自己的服务器，不需要 API 密钥，不需要任何一台电脑开机。

---

## 部署（只需做一次，约 3 分钟）

1. 在 GitHub 上新建一个**公开**（Public）仓库，名字随意，比如 `brent-diesel-tracker`。
   不要勾选 "Add a README file"，保持空仓库。
2. 把本目录的全部文件上传到仓库根目录。
   - 网页上传：仓库首页 → **Add file** → **Upload files** → 把本文件夹内的所有文件拖进去 → Commit。
   - 注意：`.github` 是隐藏目录，拖拽可能漏掉。上传后务必确认仓库里有
     `.github/workflows/scrape.yml` 这个文件，否则定时任务不会生效。
3. 开启网页托管：仓库 **Settings** → **Pages** →
   - Source 选 **Deploy from a branch**
   - Branch 选 **main**，目录选 **/docs**
   - 点 **Save**
4. 等 1–2 分钟，页面地址是 `https://<你的用户名>.github.io/<仓库名>/`
   价差页是 `https://<你的用户名>.github.io/<仓库名>/spread`
5. 验证定时任务：仓库 **Actions** 标签页 → 左侧「抓取行情并更新台账」→
   右侧 **Run workflow** → 运行一次。绿色对勾即表示成功。

## 数据是怎么流转的

```
GitHub Actions（cron 每 30 分钟）
  └─ node scripts/scrape.js
       ├─ 抓新浪日线        → brent
       ├─ 抓东财布伦特日线   → emBrent
       └─ 抓东财柴油日线     → gasoil
       ↓ 合并进 data/store.json（开盘价一经记录不再改动）
       ↓ 生成 docs/data.json
  └─ git commit && git push
       ↓
GitHub Pages 检测到变更 → 1 分钟内自动重新发布
```

**只有数据真的变了才会提交。** 周末、休市、行情无波动时不产生任何 commit，
仓库历史保持干净。

## 本地预览

页面用 `fetch('./data.json')` 读数据，直接双击 HTML 会被浏览器的同源策略拦住，
所以需要起一个本地服务：

```bash
node scripts/serve.js
# 打开 http://127.0.0.1:8123/
```

重新抓一次数据：

```bash
node scripts/scrape.js
```

只需 Node 18 以上，**没有任何 npm 依赖，不需要 npm install**。

## 为什么首页和价差页的布伦特价格可能不一样

两家数据商对「连续合约」的换月规则不同，换月窗口前后差值可达 2–3 美元。

- **首页**沿用新浪口径，与 `finance.sina.com.cn/futures/quotes/OIL.shtml` 一致
- **价差页**用东财两条线，让布伦特与柴油共用同一套连续规则，
  这样两条线才能用同一个交易日历逐日对齐，算出来的价差才自洽

刻意不统一：强行统一会让某一页的前收和开盘价自相矛盾。

## 关于「柴油」与新加坡 EN590 的关系

- ICE Low Sulphur Gasoil（低硫柴油）与 EN590 同为 **10ppm 超低硫柴油**规格，交割地 ARA，
  是全球柴油定价的公开基准。
- 新加坡 EN590 现货成交价 = **MOPS（Platts Singapore 10ppm）± 升贴水**。
  MOPS 是付费数据，**没有任何免费接口**。
- 因此本页给出的是**可公开自动获取的柴油基准**，用于跟踪柴油对原油的溢价走势，
  **不等同于新加坡现货成交价**。通常两者相差 5–20 美元/吨。

如果将来接入 Platts 订阅数据或实际成交价，注意：那些属于商业敏感数据，
**不可放在公开仓库**，需转为私有仓库（GitHub Pages 私有仓库需 GitHub Pro）。

## 已知限制

1. **国内访问 `github.io` 可能不稳定**，取决于当天网络。需要长期稳定访问可绑定自定义域名 + CDN。
2. **定时任务不保证准时**。GitHub 官方明确说明高峰期可能延迟十几分钟甚至跳过某次。
   对「每日开盘价」无影响（一天记一次），盘中高/低点的时间戳会有偏差。
3. **仓库连续 60 天无任何提交，GitHub 会自动停用定时任务**。
   本项目每个交易日都会产生提交，因此不会触发；若长期停市，需在 Actions 页手动重新启用。
4. **公开仓库的数据对全网可见**。当前仅含公开行情，无敏感信息。

## 口径说明

- 「开盘价 / 最高 / 最低」取当日对应字段；当日行随盘变动，历史行固定。
- 「前收」为上一交易日收盘价，跳空 = 开盘价 − 前收。
- 柴油按 **1 吨 = 7.45 桶** 折算成美元/桶后与布伦特对比。
- 数据源存在历史脏数据（2013 年 6–7 月柴油曾出现被放大 10 倍的异常值），
  脚本已按合理价格区间自动剔除。
- 行情为延时数据，仅供记录与研究，不构成交易依据。

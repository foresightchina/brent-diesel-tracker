记录方式　归档由 GitHub Actions 定时任务完成，每 10 分钟抓取一次行情，每个交易日只写入一条开盘价；开盘价当日确定后不再变动，重复抓取不会覆盖。你不必开机、不必打开本页，数据也会自动累积，全量归档在本仓库的 data/store.json。
实时行情　页面顶部的“最新价 / 最高 / 最低”由浏览器打开时直接向东方财富行情接口获取，每 30 秒跟随一次，不依赖后台任务是否准时。右上角同时显示两个时间：实时是行情快照时间，归档是后台落盘时间。外盘期货行情通常有 10–15 分钟延时。
容错机制　数据取自新浪财经日线接口，每次同步都会全量比对台账。即使任务中断数日，恢复后也会把缺失交易日的开盘价自动补齐，台账不会出现断档。
口径说明　本页并列展示两个口径。新浪取外盘期货布伦特原油连续合约（OIL），是主口径：顶部大数字、图表、表格「开盘价」列都用它；东财取布伦特当月连续合约，作为副口径，出现在主数字下方的对照条、表格每行的小字、以及「两个口径对照」卡片里。两者换月日不同，平时基本重合，换月前后可能差出 2–5 美元，这个差值本页照实显示、不做修正。跳空 = 开盘价 − 前收，在同一口径内计算。行情为延时数据，仅供记录核对，不构成交易依据。
